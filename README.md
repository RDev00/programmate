# Nex0 Reborn
App built for improve AI Agents brain with markdown linked files between them, letting them having knowledge about your enterprise or your brand.

## Development

### Technologies
- NextJS as Framework
- TypeScript as Languaje
- TailwindCSS as Classes gestor
- pnpm as Package Manager
- GLM 5.3 Flash as AI Agent
- Zed as Autocompleter and IDE

### Node scripts
``` bash
# Node modules instalation
pnpm install

# Project preview
pnpm dev

# Project production
pnpm build
pnpm start
```

### Env settings
```bash
SUPABASE_URL=string
SUPABASE_KEY=string
```
